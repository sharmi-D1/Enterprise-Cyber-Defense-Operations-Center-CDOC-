# Enterprise Cyber Defense Operations Center (CDOC)

## Overview

The Enterprise Cyber Defense Operations Center (CDOC) is a virtualized Security Operations Center lab built using VMware Workstation to simulate an enterprise security monitoring environment.

The project focuses on practical implementation of endpoint telemetry collection, centralized SIEM monitoring, security detection development, network traffic analysis, and vulnerability assessment.

## Objectives

- Build a controlled enterprise-style SOC environment
- Collect and analyze Windows endpoint security telemetry
- Centralize logs using Splunk Enterprise
- Develop security detections using endpoint telemetry
- Analyze network traffic using Wireshark
- Perform vulnerability assessment using OpenVAS
- Document the security monitoring workflow and technical implementation
